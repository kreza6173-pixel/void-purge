Advanced (root only)

ROOT

Root was detected on this device. This section reaches into internal system paths (/data) — more powerful, but more sensitive. Only operations that are genuinely safe (precise cache, diagnostic logs, truly-uninstalled app data) are included; nothing here ever wipes a whole app's data or touches critical system files.

☠️

Full Leftover App Data (Corpse Finder)

ROOT

Unlike the "Orphaned Files" card above (which only sees sdcard), this reaches into /data/user/0 — where real leftover data (not just cache) from uninstalled apps lives, and which even non-root cleaners can't see. Only folders whose name matches a real package-id format (com.example.app) and aren't in the installed list are shown.

📦

Precise Per-App Cache (selective)

ROOT

Instead of blindly trusting the system, this shows the exact cache size per app and lets you pick which ones to clear. Only the contents of the cache/code_cache folders are removed — never the folder itself, never anything else.

🩹

System Diagnostic Logs (ANR/Tombstone)

ROOT

/data/anr and /data/tombstones are just crash/freeze reports for debugging — no app depends on them. Clearing them is always safe and sometimes frees hundreds of MB.
